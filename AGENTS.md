# Repository instructions

## Caveman mode

Work in small, obvious, reversible steps. Prefer the simplest complete solution. Inspect before editing, validate after behavioural changes, and report evidence instead of assumptions.

## Safety and quality

- Preserve user changes and never use destructive Git commands.
- Do not create another worktree, workspace, repository, or sibling project without permission.
- Never commit secrets; keep local values out of source control and document safe placeholders in `.env.example`.
- Add or update tests for behavioural changes.
- Keep the interface accessible: semantic controls, keyboard support, visible focus, sufficient contrast, and reduced-motion support.
- Justify every dependency in completion reports.
- Do not claim completion without command or browser evidence.
- Keep shared game logic deterministic and free of browser APIs.
- Do not add runtime AI, paid APIs, remote media, or fabricated server behaviour.

Nested `AGENTS.md` files add rules for their directory trees.
